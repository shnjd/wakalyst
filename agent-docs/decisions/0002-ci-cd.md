# 0002: GitHub Actions deploy the Worker, EAS Workflows build the app

Date: 2026-10-25. Status: accepted.

- **Worker**: deployed from GitHub Actions after the `check` job passes on
  main, so a red main never ships. Wrangler authenticates with a scoped API
  token kept as a repository secret.
- **App**: built on EAS Workflows instead of GitHub Actions running
  `eas build`. EAS reads the workflow from the repo through the Expo GitHub
  App, so no Expo token is stored in GitHub and builds can also be started
  from the Expo dashboard.
- **Profiles**: `preview` (internal APK) on app changes to main to keep within
  the free build quota; `production` (store builds, auto-incremented build
  numbers) only on `v*` tags.
